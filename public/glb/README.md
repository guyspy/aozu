# Skinned humanoid spike fixture

`demo-humanoid.glb` is original procedural geometry generated by
`scripts/generate-skinned-humanoid.ts`. The fixture is dedicated to the public domain
under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
No external models, textures, fonts or animation data were used. Generator code
uses the repository's Apache-2.0 license. Reproduce with `pnpm generate:glb`.

The file contains 17 joints using VRM humanoid semantic names, inverse bind
matrices, normalized blended weights, a stable mesh with a `happy` mouth morph,
and a `wave` quaternion animation on rightLowerArm. It is plain glTF 2.0, not VRM.
The geometry is intentionally simple; this is a runtime fixture, not finished art.

Run `pnpm dev`, open a character, select **3D**, then adjust **Happy**, enable
**Hand prop**, **Wave** and **Bones**. Orbit by dragging; zoom with the wheel.
Disabling Wave restores bind pose. The demo is shared across previews in this tab
and resets on reload; it is not a conversion of the current 2D character.
Select **2D** to return to the existing PNG/Pixi preview.

On WebMCP browsers, `inspect_3d_character` returns capabilities and session revision;
`configure_3d_preview` accepts that `expectedRevision` and optional `happy` (0–1),
`prop`, `playing`, `skeleton` booleans. These are real Mantle alpha.14 procedures.
The UI works without WebMCP. No garment import or persistence is implemented.

`pnpm check:3d` checks GLTFLoader, bind pose, deformed vertices, morph/socket motion,
and Mantle/WebMCP invocation. It also runs in `pnpm test`; required gates are
`pnpm lint`, `pnpm test`, `pnpm build`.
See [research and deferred work](../../docs/research/3d-character-standards-and-webmcp.md).
